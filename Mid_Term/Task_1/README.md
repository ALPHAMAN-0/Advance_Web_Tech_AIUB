# Course Management REST API (NestJS)

A clean and minimal REST API for a university Course Management system built with NestJS. This project demonstrates the core NestJS architecture by separating concerns into Modules, Controllers, and Services using constructor-based dependency injection. All routes return simple string responses generated by the Service layer - no business logic lives in the Controller.

## Features

- Modular NestJS architecture (Module / Controller / Service)
- Full CRUD routes for the Course resource
- Constructor-based Dependency Injection
- Service layer holds all business logic; Controller only routes
- Simple string responses for every endpoint
- Lean folder structure ready for extension

## Getting Started

### 1. Install Node.js (LTS)
Download from https://nodejs.org

### 2. Install the NestJS CLI globally
npm i -g @nestjs/cli

### 3. Create the project
nest new courseManagementAPI
Choose npm as the package manager when prompted.

### 4. Move into the project
cd courseManagementAPI

### 5. Generate the Course module, controller, and service
nest g module course
nest g controller course
nest g service course

### 6. Replace the generated files (see Implementation below)

### 7. Run the project
npm run start:dev

### 8. Verify
Open http://localhost:3000 in your browser.

## Implementation

### src/course/course.service.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class CourseService {
 getCourseById(id: string): string {
 return `Course with ID ${id} has been retrieved.`;
 }

 createCourse(): string {
 return 'A new course has been successfully created.';
 }

 updateCourse(): string {
 return 'The course details have been updated.';
 }

 deleteCourse(): string {
 return 'The course has been successfully deleted.';
 }
}

### src/course/course.controller.ts
import { Controller, Get, Post, Patch, Delete, Param } from '@nestjs/common';
import { CourseService } from './course.service';

@Controller('course')
export class CourseController {
 constructor(private readonly courseService: CourseService) {}

 @Get(':id')
 getCourse(@Param('id') id: string): string {
 return this.courseService.getCourseById(id);
 }

 @Post()
 createCourse(): string {
 return this.courseService.createCourse();
 }

 @Patch()
 updateCourse(): string {
 return this.courseService.updateCourse();
 }

 @Delete()
 deleteCourse(): string {
 return this.courseService.deleteCourse();
 }
}

### src/course/course.module.ts
import { Module } from '@nestjs/common';
import { CourseController } from './course.controller';
import { CourseService } from './course.service';

@Module({
 controllers: [CourseController],
 providers: [CourseService],
})
export class CourseModule {}

### src/app.module.ts (make sure CourseModule is imported)
import { Module } from '@nestjs/common';
import { CourseModule } from './course/course.module';

@Module({
 imports: [CourseModule],
})
export class AppModule {}

## Architectural Rules Followed

- No business logic inside the Controller - every route delegates to the Service.
- All responses are simple strings returned from the Service layer.
- Dependency Injection is implemented through the constructor.
- Module / Controller / Service separation is respected.
- Project structure is lean and properly organized.
